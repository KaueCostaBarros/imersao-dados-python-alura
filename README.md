# 📊 Dashboard Interativo de Análise de Dados

Projeto desenvolvido durante a **Imersão de Dados com Python da Alura**, com o objetivo de criar um dashboard interativo para análise e visualização de dados utilizando Python e Streamlit.

O projeto permite explorar informações de forma dinâmica por meio de filtros, gráficos e indicadores, proporcionando uma análise intuitiva e interativa.

## ▶️ Como executar o projeto

### Clone o repositório

```bash
git clone https://github.com/KaueCostaBarros/imersao-dados-python-alura.git
```

### Acesse a pasta

```bash
cd imersao-dados-python-alura
```

### Crie um ambiente virtual (opcional)

Windows

```bash
python -m venv venv
venv\Scripts\activate
```

Linux/Mac

```bash
python3 -m venv venv
source venv/bin/activate
```

### Instale as dependências

```bash
pip install -r requirements.txt
```

### Execute o projeto

```bash
streamlit run app.py
```
